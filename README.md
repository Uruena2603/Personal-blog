# Personal website

Personal site of Juan Alejandro Urueña Serna, full-stack developer.

**Live:** [juan-alejandro-uruena.pages.dev](https://juan-alejandro-uruena.pages.dev/) · [Español](https://juan-alejandro-uruena.pages.dev/es/)

## Stack

Bilingual static site built with Astro and React islands: pre-rendered HTML for SEO and Open Graph, with JavaScript only where a component needs it. All copy lives in typed dictionaries, one per language. Deployed on Cloudflare Pages. Every push to `main` builds and ships automatically.

## How it is built

This repository is developed with AI agents (Claude Code, OpenCode) under a written engineering cycle: define, plan, build, verify, review, ship. Every change starts with a specification that states what is being built and how we will know it is done. That specification becomes a plan of small, verifiable tasks, approved before any code is written. The code is built in thin slices, each one tested before the next, and the result is checked against evidence from real runs, never against assumptions. An independent review covers correctness, readability, architecture, security, and performance before the change ships. The cycle and its skills come from the open-source [agent-skills](https://github.com/addyosmani/agent-skills) plugin by Addy Osmani.
